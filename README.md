# Web Resume
 
A personal resume built with HTML and CSS, formatted to match Lewis University's standard resume template, and published as a live website via Azure Static Web Apps.

## Live Site
 
[Web Resume Link](https://gray-mud-08cc83110.1.azurestaticapps.net/)
 
## Overview
 
This project implements a resume as a static web page, following the Lewis University resume format. It includes:
 
- An HTML/CSS web version of the resume
- A print-optimized stylesheet for generating a clean PDF version
- A downloadable/viewable PDF version linked from the page
## Project Structure
 
```
.
├── index.html      # Resume content and structure
├── index.css       # Styling, including print-specific rules
├── resume.pdf      # Printable PDF version of the resume
└── README.md
```
 
## Running the Project Locally
 
This is a static HTML/CSS site — there is no build step or compilation required.
 
1. Clone the repository:
```
   git clone <your-repo-url>
   cd web-resume
```
2. Open `index.html` directly in a browser (double-click the file, or right-click → Open With → your browser of choice).
No server, dependencies, or installation is required to view the resume locally.

## Deployment
 
Changes pushed to the `main` branch are automatically built and deployed via the GitHub Actions workflow in `.github/workflows/`, which publishes the site to Azure Static Web Apps. No manual deployment steps are needed once the Azure/GitHub connection is set up.

## Built With
 
- HTML5
- CSS3 (including `@media print` for print/PDF formatting)
## Hosting
 
Deployed using [Azure Static Web Apps](https://azure.microsoft.com/en-us/products/app-service/static), connected to this GitHub repository via GitHub Actions (`.github/workflows/`). Any push to the main branch automatically redeploys the site.
 
## PDF Version
 
The PDF was generated by printing `index.html` to PDF from the browser, using the print-specific styling defined in `index.css` to ensure clean margins, page breaks, and no browser-added headers/footers or page numbers. It's linked directly from the resume page.
